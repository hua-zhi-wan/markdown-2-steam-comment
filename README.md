# Markdown → Steam BBCode 转换器

一个**纯本地运行**的单页网页工具：在左侧输入 Markdown，右侧实时预览并生成可直接粘贴到 Steam 评论、指南与创意工坊的 BBCode。无需安装、无需服务器、无需联网，文本不会离开你的浏览器。

## 特性

- 基于成熟开源库 [marked](https://github.com/markedjs/marked) 解析 Markdown（GFM），不手写解析器
- 覆盖 Steam 官方支持的全部常用 BBCode 标签：标题、粗斜体、删除线、链接、图片、引用、代码、列表、表格、分割线等
- 扩展语法：`++下划线++`、`!!!剧透内容!!!`
- Steam 不支持的格式会安全降级，并给出**带原始行号**的警告 / 提示
- 视觉预览模拟 Steam 深色风格；独占一行的 YouTube / Steam 裸链显示为小组件占位
- 零构建运行：双击 `index.html` 即可使用

## 使用方法

1. 下载或克隆本仓库到本地；
2. 双击打开 `index.html`（推荐 Chrome / Edge 等现代浏览器）；
3. 在左栏编写或粘贴 Markdown，右栏实时显示结果；
4. 通过「视觉预览 / BBCode 代码」选项卡切换查看渲染效果与源码；
5. 点击顶栏「复制 BBCode」，直接粘贴到 Steam 评论、指南或个人资料中。

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构：顶栏、双栏编辑区、格式说明弹窗 |

| `converter.js` | Markdown token → Steam BBCode 的转换逻辑与警告收集 |
| `preview.js` | BBCode → HTML 预览渲染器（模拟 Steam 实际效果） |
| `app.js` | UI 交互：实时转换、复制、选项卡、帮助弹窗 |

> 「格式说明」弹窗在运行时直接读取本 README 并渲染，不维护第二份内容。注意：浏览器以 `file://` 方式直接双击打开时，安全策略会禁止页面读取本地 README，此时弹窗会给出直接查看 README 的链接；通过任意本地静态服务器（如 `python -m http.server`）打开则可正常内联显示。

## 支持的 Markdown 格式

<!-- HELP:START -->
本工具将常见 Markdown（含 GFM）语法转换为 Steam 支持的 BBCode。下表列出全部支持的写法；Steam 不支持的格式会被安全降级，并在右栏上方给出带行号的提示。

### 支持的转换

| Markdown 写法 | Steam BBCode | 说明 |
|---|---|---|
| `#`、`##`、`###` | `[h1]`、`[h2]`、`[h3]` | 标题，仅限 1–3 级 |
| `**粗体**` | `[b]…[/b]` | `__粗体__` 等价 |
| `*斜体*` | `[i]…[/i]` | `_斜体_` 等价 |
| `~~删除线~~` | `[strike]…[/strike]` | — |
| `++下划线++` | `[u]…[/u]` | 扩展语法（标准 Markdown 无下划线） |
| `***粗斜体***` | `[b][i]…[/i][/b]` | 样式可嵌套 |
| `` `行内代码` `` | `[code]…[/code]` | 等宽字体 |
| `` ``` `` 代码块 `` ``` `` | `[code]…[/code]` | 语言标识会被忽略并提示 |
| `[文字](网址)` | `[url=网址]文字[/url]` | 链接标题（title）会被忽略 |
| `![说明](图片网址)` | `[img]网址[/img]` | 仅支持网络图片 URL |
| `[![说明](图片)](链接)` | `[url=…][img]…[/img][/url]` | 带链接的图片 |
| `!!!剧透内容!!!` | `[spoiler]…[/spoiler]` | 点击前隐藏，可跨行 |
| `> 引用` | `[quote]…[/quote]` | 引用块 |
| `- 项目` | `[list] [*]…[/list]` | 无序列表 |
| `1. 项目` | `[olist] [*]…[/olist]` | 有序列表，序号始终从 1 开始 |
| GFM 表格 | `[table][tr][th][td]` | 列对齐会被忽略 |
| `---` | `[hr][/hr]` | 分割线 |
| `- [ ]` / `- [x]` | `☐` / `☑` | 任务框转为符号 |
| 裸 YouTube / Steam 链接（独占一行） | 保持原样 | Steam 会自动生成视频 / 商店 / 创意工坊小组件 |

### 会被忽略或降级的格式

- **四级及以上标题**（`####`–`######`）：Steam 不支持，自动降级为粗体；
- **表格对齐、代码语言、链接 title、HTML 属性**：Steam 无对应能力，直接忽略；
- **嵌套列表**：Steam 列表不支持嵌套，子项会被展平；
- **脚注**（`[^1]`）、**数学公式**（`$…$`）、**高亮**（`==文字==`）：无对应标签，保留 / 还原为普通文字；
- **YAML 前置元数据**（文件开头 `---` 包裹的配置块）：直接移除；
- **HTML 标签**：`<b>`、`<i>`、`<u>`、`<s>`、`<a>`、`<img>` 等 Steam 可识别的会转换；`<script>`、`<style>`、`<div>` 等不支持的标签会被移除（保留其中的文字）；
- **非 http(s) 链接**（如 `javascript:`、`file:`）：转为纯文本并警告；未写协议的链接会自动补全 `https://`；
- **无法解析的引用链接**：提示定义缺失，按普通文本处理。

### 小提示

- 警告信息会显示在右栏上方，并附带**原始 Markdown 行号**，方便定位与修改；
- 勾选左栏「保留原始换行」，可将单个回车（软换行）也转换为 Steam 中的换行；
- 转换完成后点击「复制 BBCode」，即可直接粘贴到 Steam 评论 / 指南 / 创意工坊 / 个人资料中。

## 开发

本项目无构建步骤，所有文件均为可直接运行的静态资源。修改本 README 中 `HELP:START` / `HELP:END` 之间的格式章节后，刷新页面即可看到最新内容，无需任何同步操作。

## 隐私

所有解析与转换均在浏览器本地完成，应用不向任何外部服务器发送数据、不收集任何信息（弹窗对 README 的读取仅发生在本地同源环境）。页脚指向 Steam 官方文档的链接是唯一的外部链接，且仅在点击时才会访问。
