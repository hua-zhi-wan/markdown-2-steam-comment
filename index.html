Markdown 写法Steam BBCode说明

        
          
# ## ###[h1] [h2] [h3]标题，仅限 1–3 级

          
**粗体**[b]…[/b]__粗体__ 等价

          
*斜体*[i]…[/i]_斜体_ 等价

          
~~删除线~~[strike]…[/strike]—

          
++下划线++[u]…[/u]扩展语法（标准 Markdown 无下划线）

          
***粗斜体***[b][i]…[/i][/b]样式可嵌套

          
`行内代码`[code]…[/code]等宽字体

          
``` 代码块 ```[code]…[/code]语言标识会被忽略并提示

          
[文字](网址)[url=网址]文字[/url]链接标题 title 会被忽略

          
![说明](图片网址)[img]网址[/img]仅支持网络图片 URL

          
[![说明](图片)](链接)[url=…][img]…[/img][/url]带链接的图片

          
!!!剧透内容!!![spoiler]…[/spoiler]点击前隐藏，可跨行

          
> 引用[quote]…[/quote]末行写 — 作者 可生成 [quote=作者]

          
- 项目[list] [*] [/list]无序列表

          
1. 项目[olist] [*] [/olist]有序列表，序号始终从 1 开始

          
GFM 表格[table][tr][th][td]列对齐会被忽略

          
---[hr][/hr]分割线

          
- [ ] / - [x]☐ / ☑任务框转为符号

          
裸 YouTube / Steam 链接（独占一行）保持原样Steam 会自动生成视频 / 商店 / 创意工坊小组件

        
      


      
会被忽略并给出提示的格式

      
    
        
  • 四级及以上标题（####–######）：Steam 不支持，自动降级为粗体；
    • 
        
  • 表格对齐、代码语言、链接 title、HTML 属性：Steam 无对应能力，直接忽略；
    • 
        
  • 嵌套列表：Steam 列表不支持嵌套，子项会被展平；
    • 
        
  • 脚注（[^1]）、数学公式（$…$）、高亮（==文字==）：无对应标签，保留/还原为普通文字；
    • 
        
  • YAML 前置元数据（--- 开头的配置块）：直接移除；
    • 
        
  • HTML 标签：<b> <i> <a> <img> 等 Steam 可识别的会转换；<script> <style> <div> 等不支持的标签会被移除；
    • 
        
  • 无法解析的引用链接：提示定义缺失，按普通文本处理。
    • 
      


      
提示：警告信息会显示在右栏上方，并附带原始行号，方便定位与修改。
